# Wayfind prebuild guard manifest — ONE GUARD PER LINE.
#
# Why this file exists: every guard used to be appended to a single ~8KB
# "prebuild" line in package.json. Two branches adding a guard ALWAYS collided
# there, even though their additions never overlapped — that one line conflicted
# four times on 2026-07-28 alone. One guard per line + "merge=union" in
# .gitattributes means git resolves concurrent additions by itself.
#
# Rules:
#   - Lines starting with # are comments. Blank lines are ignored.
#   - Order is execution order. Cheap/structural guards first.
#   - Duplicates are de-duplicated by the runner (a union merge can create them).
#   - ADDING a guard here is all you need. Do NOT touch package.json.
#   - A guard-shaped file (scripts/check-*.mjs or scripts/test-*.mjs) that is
#     NOT listed here must be declared in the EXCLUDED list in
#     scripts/check-guard-manifest.mjs, with a reason. That meta-guard is what
#     stops a guard from being silently forgotten.
