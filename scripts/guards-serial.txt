# scripts/guards-serial.txt — guards that must run ALONE, never in the parallel pool.
#
# Read by scripts/run-guards.mjs (see its header). One EXACT guard line per entry,
# identical to the line in scripts/guards.txt; "#" lines are comments. The runner runs
# every other guard through a worker pool first, then runs these one at a time, in
# manifest order. An entry that is not in guards.txt fails the whole run (a renamed
# guard must not quietly lose its protection). Union-merged like guards.txt.
#
# HOW THIS LIST WAS BUILT (2026-10-27): every one of the 995 guards was run under
# `strace -f` and every file it created, wrote, renamed or deleted, and every port it
# bound, was recorded; that was cross-checked against a source grep for listen(,
# fixed ports, tmpdir()/"/tmp/", writes into the repo tree and chromium/playwright.
# A guard is parallel-safe only if every path it writes is minted uniquely per run
# (mkdtemp, or pid + random) AND outside the trees other guards scan (app/, lib/,
# scripts/). Anything else is listed here. Be conservative: when in doubt, list it.
#
# ADDING A GUARD: do nothing unless it writes a fixed path, writes inside app/ lib/
# scripts/ or any tracked file (even temporarily, e.g. a red-prove mutation), runs
# git against the live work tree, binds a fixed port, or launches a browser. Then add
# its exact line below with the reason.
