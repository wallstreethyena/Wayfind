# Wayfind voice

Owner direction, 2026-09-19: keep public copy short, sharp, confident and useful.
Wit is welcome when it helps. Cut process explanations, repeated instructions and
self-congratulation. Lead partner ticket links with Wayfind's recommendation using
`lib/partnerCopy.js`; keep the actual seller and ticket type clear. Say “best deal,”
“special offer,” “exclusive” or a savings amount only when current evidence supports
that exact claim. Required disclosures stay concise; do not add optional disclosure
paragraphs. Prefer clear actions and useful trip details over explaining how Wayfind
works. Apply this voice to future writing and edits.
